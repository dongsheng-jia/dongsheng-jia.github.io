Dongsheng Academic Serif: page-specific Chinese webfont
======================================================

Original fonts: Noto Serif CJK SC Regular and Bold
Sources: NotoSerifCJK-Regular.ttc and NotoSerifCJK-Bold.ttc, collection face 2.
Original PostScript names: NotoSerifCJKsc-Regular and NotoSerifCJKsc-Bold

Outputs:
- dongsheng-academic-serif-sc.woff2: Regular, 400
- dongsheng-academic-serif-sc-bold.woff2: Bold, 700
Family: Dongsheng Academic Serif
PostScript names: DongshengAcademicSerif-Regular and DongshengAcademicSerif-Bold

Changes:
- Retained the non-ASCII characters appearing in the visible text of
  index.html and in assets/main.js (including alternate text and strings).
- Extended the retained character set with 邮箱：铅笔素描头像 for the email
  label and updated portrait alternate text; all previous characters remain.
- Extended the retained character set for the revised research-interest
  sentence below; all previous characters remain.
- Extended the retained character set for Research/Idea page headings,
  navigation, and the research-methods introduction; all prior characters
  remain. Latin letters continue to use the Latin Modern webfont.
- Extended the retained character set for the final Idea introduction,
  preserving all prior characters; generated matching Regular and Bold
  subsets from their respective original faces.
- Converted the subset to WOFF2 for local web delivery.
- Renamed the family, full, unique, PostScript, typographic, and CFF font
  names to distinguish this derivative from the original Noto family.
- Preserved glyph outlines and horizontal metrics for retained characters.
- Preserved original copyright and license metadata within the font.

This derivative is distributed under the SIL Open Font License 1.1.
The original Noto CJK copyright notice and complete OFL license are retained
alongside the fonts in this repository. The original authors do not provide
support for this page-specific subset.
